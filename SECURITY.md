# Security policy

Theme Forge writes live user configuration only through explicit `--apply`
operations. Please report path traversal, symlink handling, rollback integrity,
command execution, or unsafe configuration mutation issues privately through
GitHub's security advisory feature rather than a public issue.

Do not include credentials, private configuration, or unredacted personal data
in a report. There is currently no long-term support branch; fixes target the
latest `master` revision.
